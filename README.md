# 🍔 Dev Fast Food — Vrindavan

A fast, responsive, and modern website built for **Dev Fast Food**, a popular pure vegetarian street-food destination located near Banke Bihari Mandir, Vrindavan.

---
## URLs : - **https://dev-fast-food-restaurant.vercel.app/**
## 🌟 Features

* **Interactive Hero Slider:** Smoothly transitions through signature menu items with a dark, high-contrast theme.
* **Full Digital Menu:** Categorized food menu (Burgers, Pizzas, Sandwiches, Chinese, Momos, and Pasta) with real pricing.
* **Instant WhatsApp Ordering:** Fully frontend-driven shopping cart that calculates total bill and forwards the entire order directly to the restaurant's WhatsApp.
* **Responsive Design:** Optimized for mobile phones, tablets, and desktop browsers.
* **Vrindavan Dedicated:** Custom branding, local address highlights, and operating hours.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, Vanilla JavaScript
* **Icons & Fonts:** Google Fonts (Poppins)
* **Hosting / Deployment:** Vercel
